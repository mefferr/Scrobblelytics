# Scrobblelytics

just a custom app for spicetify that shows your last.fm stats right inside spotify. 

it adds a bunch of tabs so you can check your top artists, tracks, recent scrobbles, listening times, and some weird nerd stats (gini coefficients, entropy, etc). it doesn't use any heavy frameworks so it just blends in with whatever spotify theme you have installed.

## install
the easiest way is to just grab it from the spicetify marketplace.

if you want to do it manually:
1. clone this repo into your spicetify `CustomApps` folder
2. rename the folder to `Scrobblelytics`
3. run `spicetify config custom_apps Scrobblelytics`
4. run `spicetify apply`

## setup
once it's installed, just open the tab and type in your last.fm username. you don't need any api keys or login authorization.
