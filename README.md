# Scrobblelytics 

A powerful, standalone Last.fm statistics dashboard for Spicetify.
*Deep analytics for your listening history.*

## Features
* **10 Deep-Dive Tabs:** Overview, Top Artists, Tracks, Albums, Recent Log, Genres, Listening Clock, Trends, Deep Dive, and Nerd Stats.
* **Native Aesthetic:** Clean UI that perfectly matches standard Spicetify themes.
* **No Authentication Required:** Just enter your Last.fm username on setup.
* **Data Visualization:** Built-in heatmaps, bar charts, and cumulative concentration graphs.
* **Nerd Stats:** Calculates Gini coefficients, Shannon entropy, loyalty scores, and one-hit wonder ratios.
* **Lightweight:** Pure vanilla JavaScript, no heavy React dependencies or build steps required.

## Installation (Marketplace)
Search for **Scrobblelytics** in the Spicetify Marketplace.

## Manual Installation
1. Clone this repository into your Spicetify `CustomApps` folder.
2. Rename the folder to `Scrobblelytics`.
3. Run `spicetify config custom_apps Scrobblelytics`
4. Run `spicetify apply`
